# تشغيل سيرفر Laravel على الشبكة المحلية (LAN)

دليل لتشغيل الباك اند بحيث يقدر يوصله أي جهاز ثاني (موبايل حقيقي، جهاز آخر) على نفس شبكة الواي فاي، بدل الوصول من نفس الجهاز فقط.

## لماذا؟

`php artisan serve` الافتراضي يعمل على `127.0.0.1` (loopback) — عنوان خاص بالجهاز نفسه فقط. أي جهاز ثاني على الشبكة، أو تطبيق Flutter شغّال على موبايل حقيقي، ما يقدر يوصله لأن `localhost`/`127.0.0.1` بالنسبة لهم تشير لأنفسهم وليس لجهاز الكمبيوتر.

الحل: تشغيل السيرفر على `0.0.0.0` (استمع على كل كروت الشبكة) بدل `127.0.0.1`.

## الخطوات

### 1. تأكد من مسار PHP

إذا ظهر خطأ `php: command not found`، فهذا يعني أن PHP غير مضاف لمتغير `PATH`. تأكد من مكان تثبيته (مثال مع Laragon):

```
C:\laragon\bin\php\php-<version>\php.exe
```

الحل الدائم: أضف هذا المجلد إلى `PATH` من System Properties → Environment Variables، حتى تقدر تكتب `php` مباشرة بأي طرفية جديدة.

### 2. شغّل السيرفر مع `--host=0.0.0.0`

من مجلد `backend`:

```bash
php artisan serve --host=0.0.0.0 --port=8000
```

أو بالمسار الكامل إذا PHP مو بالـ PATH:

```bash
"C:\laragon\bin\php\php-8.3.33-Win32-vs16-x64\php.exe" artisan serve --host=0.0.0.0 --port=8000
```

### 3. اعرف IP جهازك على شبكة الواي فاي

```powershell
Get-NetIPAddress -AddressFamily IPv4 | Where-Object InterfaceAlias -eq "Wi-Fi"
```

⚠️ تنبيه: إذا كان عندك VPN أو Tunnel شغّال (مثل ProTUN)، رح يظهر لك أكثر من IP. اختر العنوان اللي يقابل كرت "Wi-Fi" أو "Ethernet" الحقيقي، مش كرت الـ VPN الوهمي.

### 4. جرّب من جهاز ثاني على نفس الشبكة

```
http://<IP-الجهاز>:8000
```

### 5. عدّل رابط الـ API في تطبيق Flutter

لأن الموبايل الحقيقي لا يفهم `localhost` كإشارة لجهاز الكمبيوتر، لازم تستبدل الرابط في:

- [frontend/.env](../../frontend/.env)
- [frontend/lib/core/network/dio_client.dart](../../frontend/lib/core/network/dio_client.dart)

من `http://127.0.0.1:8000` أو `http://localhost:8000` إلى `http://<IP-الجهاز>:8000`.

> ملاحظة: هذا IP يتغيّر إذا تغيّرت الشبكة (بيت/جامعة/شغل) أو أعاد الراوتر توزيعه — إذا توقف الاتصال فجأة، أول شي تتأكد منه هو أن IP لسا نفسه.

### 6. إذا ما اشتغل رغم كل شي: الجدار الناري

Windows Defender Firewall ممكن يمنع اتصالات داخلة (inbound) جديدة على البورت من أجهزة ثانية. اسمح لـ PHP أو للبورت 8000 بالمرور عبر الشبكات الخاصة (Private networks) من إعدادات جدار الحماية.

## تنبيه أمني

تشغيل السيرفر على `0.0.0.0` يجعله متاحًا لأي جهاز على نفس الشبكة المحلية فقط (ليس الإنترنت) طالما الراوتر لا يعمل port forwarding. هذا مقبول للتطوير المحلي، لكن `php artisan serve` أصلاً غير مخصص للإنتاج بأي حال من الأحوال.
